# biocomputing-project-1
First Personal computational biology project with public biomedical data.

Project descriptions:\
Personal computational project to investigate gene-expression changes associated with cardiovascular diseases using public GEO datasets. The research will deal with reproducible analysis using Python and R, including data set selection and quality, data analysis, visualization, and biological interpretation.
